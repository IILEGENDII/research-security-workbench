# Local formats, version 1

The receipt binds its ID, policy, check, asset, supported contract, tool version, collection method, data class, declared or observed times, exit status, byte length and SHA-256. The raw report is the exact content of report.json beside receipt.json. Captures also identify the executable and input digests. Assessments bind normalized results and provenance to one policy and evaluation time. Comparisons require compatible policies. All documents use UTF-8 JSON.
