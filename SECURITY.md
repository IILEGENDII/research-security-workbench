# Security

The supported upstream versions and report contracts are listed in [Integration contracts](docs/integration-contracts.md). Reproduce suspected defects on disposable synthetic assets under your control. Include the version, a minimal synthetic input, the expected policy outcome and the observed outcome. For a non-sensitive defect, open a repository issue. Keep private paths, credentials and unpublished sensitive evidence out of public issues. Use a private reporting channel only after confirming it with the project owner.
